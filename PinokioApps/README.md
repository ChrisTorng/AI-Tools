# Pinokio launchers — moved to dedicated repositories

The initial copies here were a staging area and are **not maintained**. Use the canonical installable GitHub repositories instead:

- [Dettato Pinokio](https://github.com/ChrisTorng/dettato.pinokio) — audio to multitrack MIDI
- [Copista Pinokio](https://github.com/ChrisTorng/copista.pinokio) — scanned score/PDF to MusicXML

In Pinokio, choose **Download from URL** and enter the corresponding repository URL. Scripts must be at the repository root for that workflow.

Keep updates, issues, and installation instructions in the dedicated repositories. The old folders in AI-Tools are retained only as a historical staging snapshot.
